# CSPro Third-Party Libraries

This repository contains routines for building the third-party libraries that are used to build the [Census and Survey Processing System](https://www.census.gov/data/software/cspro.html) (CSPro) and [CSEntry Android](https://play.google.com/store/apps/details?id=gov.census.cspro.csentry).

Prebuilt libraries are available here: <https://github.com/csprousers/cspro-libraries>.

The CSPro source code is available here: <https://github.com/csprousers/cspro>.
